# AI Travel Planner

A full-stack AI-powered travel planner built with Next.js, FastAPI and PostgreSQL.

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy, Pydantic
- Database: PostgreSQL
- Auth: JWT
- AI: Google Gemini API
- Weather: Open-Meteo
- Places: Geoapify
